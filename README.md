# Delif Home

A warm, responsive landing page for Delif Home, built with plain HTML, CSS, and JavaScript so it can deploy directly to Cloudflare Pages.

## Local preview

Open `index.html` in a browser, or run any static server from this directory:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Cloudflare Pages

Use these settings for a direct static deployment:

- **Framework preset:** None
- **Build command:** Leave blank
- **Build output directory:** `/`
